# PSUSphere

**PSUSphere** is a Django-based student organization management system designed to manage student information, academic programs, colleges, organizations, and organization memberships.

The project uses **Django Admin** to make it easier to manage and organize student organization records.

---

## Project Overview

PSUSphere provides a centralized system for managing student and organization information.

The project includes database models for:

* Colleges
* Academic Programs
* Students
* Organizations
* Organization Members

It also includes an administration panel where records can be added, searched, filtered, and managed.
